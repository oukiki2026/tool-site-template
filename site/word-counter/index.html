What counts as a word?

In browsers supporting Intl.Segmenter, we count English-locale word-like segments. Contractions, punctuation, and Chinese text can differ from a whitespace-only counter. The language of your text is not detected. A browser without segmenter support uses non-empty whitespace-separated tokens.

Visible characters use grapheme segmentation when supported, so a combined accent or an emoji sequence is treated as one visible unit. The fallback counts Unicode code points. Whitespace-free counting removes Unicode whitespace before segmentation. Lines include blank lines between or after text; an entirely empty input has zero lines.

Useful for drafts, not platform limits

Use this to compare drafts, shorten an introduction, or estimate the size of text you intend to publish. A destination platform may count bytes, code units, URLs, or emoji differently. Its own posting limit remains authoritative.

About Kikomono Tools

A lightweight utility by OuKiki. No sign-up, external API, document upload, or backend processing. The text is held in this browser tab until you clear it or leave. Copy counts requires a normal browser clipboard permission and only copies the displayed totals.
