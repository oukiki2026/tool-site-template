Choose the right operation

  • Merge: select PDFs in the intended order. The file list shows the actual order; reselect if it is wrong. Check the result before sharing.
  • Extract / split: select one PDF and enter individual pages or ranges. Run again for another part. This produces one result file per operation, not a ZIP of every page.
  • Rotate: select one PDF. The selected angle is added to each page's current rotation.
  • Images: select JPG/PNG files in order. Each image becomes one PDF page with its original proportions. The tool does not perform OCR or shrink image files.

Limits and document safety

Encrypted PDFs are rejected. Large documents can exhaust your browser memory; try smaller parts. The first version accepts at most 20 files and 50 MiB total input as a conservative product limit, not a measured device guarantee. Keep your original documents and check every output page. Page copying can lose interactive forms, bookmarks or other document-level features; this tool does not promise to preserve signatures. Rewriting a signed PDF may invalidate its signature.

File bytes are read into memory in this tab and are not uploaded. The library is served from this site, with no remote conversion API. Clear releases file references and the result download; closing the tab ends this processing session. Downloads remain on your device until you delete them. Browser extensions and device security remain outside this tool's control.

When you need another tool

For scanned-text recognition, existing text editing or advanced form handling, evaluate a dedicated editor. Read our AI beginner workflow before giving any agent access to private files. The word counter remains available for text work.
